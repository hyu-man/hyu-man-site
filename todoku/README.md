# とどく。

公開先: https://hyu-man.com/todoku/

2026年11月29日。ひゅーまんの依頼「この論文が正しかったら」に基づく、音の出ないインタラクティブ映像作品。

## 参照

Venkatesa Chandrasekaran, *An algebraic quantization of gravity from the null cone*, arXiv:2611.34924v1, 2026-11-25投稿。
https://arxiv.org/html/2611.34924v1

第1・3・5節の因果ダイヤモンド、光的境界、領域の接合を着想源にした。論文の成立・査読状況を認定するページではない。

「ひらく」の基本形だけは、空間を2次元に省略した平坦な時空で、光速を1とした `r + |t| = span / 2` を使う。図の縦軸は時間で、普通の3次元空間内の立体ではない。カメラを傾けても時間の向きは図の上下。

「ゆらす」の変形と「つなぐ」の2領域の受け渡しは創作。重力の拘束条件、量子振幅、論文の接合演算は計算していない。点の数をヒルベルト空間の次元や量子状態数に対応させていない。

## 操作と実装

- ドラッグ／矢印: 図を回す。クリック／Enter／「光を送る」: 光の波を加える。
- Space（図にフォーカス中）／停止ボタン: 再生・停止。
- 「ふたつの瞬間のあいだ」: 図の時間幅を変える。作品内の相対値。
- 「かたちのゆらぎ」: 芸術的な変形。ひらくから操作するとゆらすに切り替わる。
- prefers-reduced-motionでは初期停止。タブ非表示中は時間・描画を停止。Canvas 2D、追加JSライブラリなし。
- 編集元 `todoku/`。公開用は `public/todoku/`。HTML・CSS・JS・poster.pngをそろえる。READMEと画像生成スクリプトは公開不要。
- `node tests/todoku.mjs`: 光円錐の境界・接合点・投影の有限性。
- `python scripts/todoku-poster.py`: Pillowで共有画像を生成。
