規則を重ねると、曲になる。音符は置かない。規則と種を置く。

0 : 0

4つの規則が、同じ拍で歩いています。一歩が一拍（蟻とそろうは 16分、コラッツは 8分、ライフは 4分）。
音符はどこにもありません。種を変えると、曲が変わります。同じ種なら、何度でも同じ曲。
乱数は入っていません。種から並びを作るのも、決まった計算です。

ライフが全部きえたら、そのトラックは黙ります。 種を変えてください。
コラッツが 1 に帰ったら、長い音を一つ出して、休んでから、また種から出発します。
そろうは、そろって撃ったあと 8拍休んで、また並び直します。

WAV は、いま鳴っているのと同じ計算をもう一度回して作ります。MIDI は同じ音を音符に写したもので、DAW に持っていけます。
「この曲のリンク」は、種と速さを URL に書きます。曲を送るのに、ファイルは要りません。
