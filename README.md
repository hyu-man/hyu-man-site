# hyu-man.com

規則をひとつ決めて、走らせて、出てきたものを置いてあります。

手で書いた HTML です。ビルドはしません。npm も使いません。
外から読み込むのは Google Fonts だけです。

---

## 部屋

白なら右。黒なら左。踏んだ色を裏返して、一歩。
**この蟻から、5つ出ています。**

`/ant/` ひとり ・ `/read/` よむ ・ `/play/` かなでる ・ `/loop/` まわす ・ `/chop/` きざむ

隣が2か3ならいきる。ちょうど3でうまれる。それ以外はきえる。
**規則の中に、最初からカエルがいました。**

`/life/` いきる ・ `/toad/` かえる

偶数なら半分。奇数なら3倍して1を足す。
**ぜんぶ 1 にかえります。たぶん。**

`/collatz/` 1にかえる

テープの上を、きまった規則どおりに歩くだけ。
**とまるかどうかは、調べる方法がありません。**

`/halt/` とまる ・ `/count/` かぞえる ・ `/liar/` うそつき

規則が出した答えを、そのまま置いてあります。

`/film/` うごく

ここから、外に持ち出せます。

`/midi/` かきだす ・ `/canvas/` うつす

14部屋。ほかに `/omega-ep/` があります。4枚目の特設で、ホームからはまだ辿れません。

音源は [hyu-man.bandcamp.com](https://hyu-man.bandcamp.com)。

---

## 音

`public/js/dmg.js` は、ゲームボーイ（DMG）の音源をブラウザで鳴らします。
矩形波2つ、波形メモリ1つ、ノイズ1つ。同時に4音まで。
あとから鳴った音が、前の音を切ります。

本物の制約をそのまま入れてあるので、キックを鳴らすとベースが消えます。
サイドチェインを作る必要がありません。実機がそうなっています。

`/loop/` `/midi/` `/liar/` が使っています。

## 置き場所

ルートが編集元です。`public/` が、出す先です。

    Copy-Item .\halt\index.html .\public\halt\index.html -Force

ただし、いま両方あるのは8部屋だけです。
`/ant/` `/play/` `/loop/` `/collatz/` `/count/` `/life/` `/toad/` は `public/` にしかありません。
画像と音（`public/w/` `public/v/` `public/og/`）も `public/` だけです。
そのうち、どちらかに寄せます。

## 出しかた

    npx.cmd wrangler deploy

`wrangler.toml` に名前と `./public` が書いてあるので、引数は要りません。
Cloudflare Workers の静的アセットとして出ています。

PowerShell では `&&` が使えません。繋ぐときは `;` です。

## 気をつけること

Cloudflare は大文字と小文字を区別します。Windows はしません。
`Dmg.js` を置いて `/js/dmg.js` が404になったことがあります。

HTML に全角スペースが混ざると、幅を持ちます。見た目では分かりません。

同じ名前のファイルを何度もダウンロードすると、古いほうを置いてしまいます。
置いたら、バイト数を見てください。
