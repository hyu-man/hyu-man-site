# Contributor attribution

The owner does not want automatic assistant attribution in Git commits or pull requests.
Do not append assistant `Co-Authored-By` trailers, model names, company names, or generated-by bylines to commits or PR descriptions.
Preserve the owner's existing Git author identity. Do not invent an assistant account or email address.
When an assistant credit is explicitly requested for a creative work, use `ω`.
This rule concerns contributor credits; it does not remove factual descriptions of how works were made.
